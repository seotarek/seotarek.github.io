SCIENTIFIC RESEARCH PAPER & DEFENSE SYSTEM

LightGuard-Agent: A Lightweight Defense Architecture Against Indirect Prompt Injection in Tool-Calling AI Agents

DOI: 10.5281/zenodo.22731104

Autonomous AI agents executing tool calls via the Model Context Protocol (MCP) and external APIs are critically exposed to Indirect Prompt Injection (IPI), homoglyph evasion, and multi-turn crescendo jailbreaks embedded in untrusted external data streams. LightGuard-Agent introduces a sub-millisecond 3-tier hybrid evaluation pipeline combining deterministic syntactic isolation, semantic heuristics, and least-privilege execution policy enforcement without external LLM dependencies.

Sub-Millisecond Latency (< 0.1 ms)

Evaluation consumes less than 1% of a single LLM inference frame, eliminating latency bottlenecks and cloud costs in high-concurrency production loops.

100.0% Adversarial Mitigation Rate

Demonstrated complete mitigation across benchmark suites with zero false positives on developer, medical, and financial tool-calling workflows.

MCP Hardening & Boundary Validation

Strict schema boundary checks preventing credential harvesting, SSRF exfiltration, and unauthorized file system traversal.

ENGINEERING PHILOSOPHY

Rigorous Engineering Principles & Systems Manifesto

Non-negotiable architectural laws governing every line of production systems code.

RULE_01

Deterministic Over Stochastic

Safety, authorization, and clinical calculators must never rely on probabilistic model inferences. Runtime security firewalls and clinical engines must execute deterministically with sub-millisecond guarantees.

RULE_02

Zero-Knowledge by Default

Process untrusted and sensitive data on-device or at the edge with zero cloud telemetry and strictly scoped local permissions.

RULE_03

Memory Safety & Extreme Scale

Systems code written in Rust must remain resilient against extreme-scale allocation boundaries (such as billion-pixel raster canvases) without unexpected panics or dangling references.

RULE_04

Verification Before Assertion

Every performance, mitigation, or compliance claim must be grounded in executable test suites, public benchmarks, or permanent scientific artifacts (Zenodo DOI).

RULE_05

Epistemic Provenance & Formal Constraints

Regulated architectures (clinical informatics, multi-tenant databases) require strict audit trails, boundary enforcement, and formal error containment.
